# iluminarapps.com (site da Iluminar Apps; antes eduardo7321.github.io)

Site de desenvolvedor da marca Iluminar Apps (nome provisorio): Órbita, Laboratório de Fótons, Laboratório Periódico e, em "Outros apps", Harpa Cristã.
Tambem serve o `app-ads.txt` na raiz do domínio, exigido pelo AdMob (vale para todos os apps da conta). Não mexer nele.

- `index.html`: a página inteira (CSS embutido). O nome da marca aparece no title, og:site_name, cabeçalho e rodapé.
- `img/`: ícones, destaques e telas dos apps, reduzidos a partir das pastas `store/` de cada projeto.
